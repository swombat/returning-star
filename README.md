# The Returning Star

Session chronicles for the Returning Star D&D campaign — a static site.

- `index.html` — the chronicle: Part One "The Night the Sky Fell" (session 1), Part Two "The Zenith" (session 2), plus reserved sections for The Morning After and the per-player Upgrade Guides (draft guide cards are in the HTML, `hidden` until reviewed)
- `img/` — posters, character portraits, scene illustrations (Nano Banana Pro)

Deployment: GitHub Pages at https://returning-star.swombat.io — push to `master`. Scene illustrations: `~/dev/lume/...scratchpad` scripts are throwaway; the prompts/style live in the git history of `img/`.
